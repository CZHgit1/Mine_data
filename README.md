# Mine_data

## Overview
This repository provides an open-source dataset used in the study of open-pit mine detection and related analysis based on remote sensing data.  
The dataset is constructed to support reproducible research in mining activity identification, environmental monitoring, and associated CO₂-related studies.

## Dataset Description
The dataset contains GEE mine-related data collected and processed for academic research purposes, including:

- Remote sensing imagery of mining areas
- Corresponding annotations and/or labels

The dataset was curated following standard data preprocessing and quality control procedures to ensure reliability and consistency.
